# Business Suite

Custom ERPNext/Frappe application for the ERPNext Business Suite project.

## Foundation

This initial implementation establishes the application package and module boundaries only. Business DocTypes, server-side domain logic, permissions, workflows, APIs, reports, integrations and tests will be added in dependency order.

## Implementation order

1. App foundation
2. Core DocTypes and data model
3. Server-side business logic
4. Permissions and roles
5. Workflows
6. APIs and integrations
7. Reports and dashboards
8. Automated tests
9. Deployment and CI/CD
